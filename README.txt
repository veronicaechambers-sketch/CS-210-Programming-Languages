Corner Grocer - CS 210 Project Three

Open CornerGrocer.sln in Visual Studio 2022, then Build and Run.
Keep CS210_Project_Three_Input_File.txt in the program working directory.
The program creates frequency.dat automatically at startup.

Source files:
- main.cpp
- ItemTracker.h
- ItemTracker.cpp

Required menu:
1. Search for an item
2. Display all frequencies
3. Display histogram
4. Exit
